# TaskFlow

A collaborative team task & project management web application — Week 1 deliverable
(Project Planning & System Architecture) for the Junior Full Stack Developer Internship.

## Contents
- `docs/TaskFlow_Project_Report.docx` — full project brief, flowcharts, wireframes,
  system architecture, and database schema.
- Source code for TaskFlow will be added in subsequent weeks of the internship as the
  application is built out (front end, back end, database migrations).

## Planned Stack
React (front end) · Node.js + Express (back end) · PostgreSQL (database) ·
Redis (cache / pub-sub) · Socket.io (real-time updates) · JWT auth.

## Status
Week 1 — planning & architecture complete. Implementation begins Week 2.
